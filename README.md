# Game 3v3 bball

Уличный баскетбол 3×3 и 1×1 в браузере: персонажи «Баскетбола Куроко» с техниками на J / K / L, турнир, трэш-ток, танцы, данки с разбитым щитом.
Работает на ноутбуке (клавиатура) и на телефоне (сенсорное управление, горизонтальный экран).

## Как играть онлайн
Открой ссылку GitHub Pages репозитория — на телефоне поверни экран горизонтально и нажми «Обычная игра».

## Управление (клавиатура)
- `W A S D` — движение, `Space` — рывок
- `U` — бросок (держи и отпусти в зелёной зоне), у кольца — лейап / данк
- `I` — дриблинг / финт (в защите — перехват), `O` — пас (в защите — запрос паса)
- `J` / `K` — техники персонажа, `L` — ульта
- `T` — понты, `Y` — танец, `P` / `Esc` — пауза и настройки, `M` — звук

## На телефоне
Джойстик слева, кнопки справа, `II` — пауза. Игра открывается во весь экран.

## Запустить у себя
Открой `index.html` в браузере или запусти `start-game.bat` (локальный сервер на порту 3456).
