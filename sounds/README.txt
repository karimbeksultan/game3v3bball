Настоящие звуки (необязательно)
================================
Положи сюда mp3-файлы с такими именами — игра будет играть их вместо синтезированных звуков.
Если файла нет, работает встроенный звук.

  swish.mp3    — мяч чисто проходит через сетку
  rim.mp3      — удар о дужку кольца
  board.mp3    — удар о щит
  bounce.mp3   — удар мяча о паркет (короткий)
  dunk.mp3     — данк / удар по кольцу
  cheer.mp3    — трибуны ревут после попадания
  groan.mp3    — трибуны разочарованно гудят после промаха
  crowd.mp3    — фоновый гул арены (играет по кругу)
  whistle.mp3  — свисток судьи
  buzzer.mp3   — сирена

Используй только звуки, которые можно свободно использовать (например, с лицензией CC0).
